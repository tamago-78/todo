# アプリ仕様書：アプリ整理アプリ（仮）

## ⚠️ 実現性メモ（最初に読む）

- **iOS版は実現不可**。iOSはセキュリティ設計上、他アプリの一覧取得・最終使用日時の取得・アンインストールを一切許可していない（そもそもAppleの審査を通らない）。iOSには標準機能「非使用のAppを取り除く」が既にある。
- **Android版は実現可能**。ただし以下の条件つき：
  - 「使用状況へのアクセス」権限（PACKAGE_USAGE_STATS）をユーザーが設定画面で手動ONにする必要がある → 初回オンボーディングで誘導画面が必須
  - アンインストールは**OSの確認ダイアログが1件ずつ出る**方式（サイレント一括削除は不可能）。「リストから選ぶ → 連続でポンポン確認していく」のが現実的なUX
  - アプリ一覧取得の権限（QUERY_ALL_PACKAGES）はGoogle Playの要注意権限。「アプリ管理ツール」は認められるカテゴリだが、申請時に利用目的の申告が必要
- よって**v1はAndroid専用**とする。初期費用はGoogle Playの約4,000円（買い切り）のみで済み、ペイのハードルも下がる。
- **自分専用ならさらにハードルが下がる**：AndroidはAPKを直接インストール（サイドロード）できるため、ストア登録なし・費用ゼロ・要注意権限の申告なしで自分の端末で使える。まず自分専用版を作り、価値を実感できたらPlay公開に進む流れが最短。
- iOSの制約はストア審査ではなく**OS自体のAPI制限**なので、自分専用（サイドロード）でも不可能。ただしiOSには設定 > 一般 > iPhoneストレージに「最終使用日順のアプリ一覧＋削除」が標準搭載されており、やりたいこと自体はこれで実現できる。

## 1. 概要

- **一言で言うと**：使っていないアプリが「開いていない期間」順に並び、その場でアンインストールできるアプリ
- **誰の、どんな不便を解決する？**：アプリをたくさんインストールしていて消すのがめんどくさい人、整理整頓が苦手な人。「どれを消していいか分からない」「1個ずつ探して消すのが面倒」を解決する
- **既存アプリとの違い**：（類似アプリはPlayストアに存在する。差別化ポイントを言語化する：例 起動して3秒で「消すべきアプリ」が見える速さ／広告控えめ／日本語で分かりやすい）

## 2. ユーザーと利用シーン

- **想定ユーザー**：スマホの容量不足や通知の多さに悩む一般ユーザー（非エンジニア含む）
- **使うタイミング**：容量不足の警告が出たとき、月1回の整理タイム
- **1日に開く回数 / 1回の滞在時間**：低頻度（月数回）× 3〜5分
  ※毎日開くタイプではないので、バナー収益は控えめの想定。滞在中はリストを眺める時間が長いのでバナーとの相性自体は悪くない

## 3. 機能一覧

### 必須（これだけでv1リリース）
- [ ] 端末内のアプリを「最後に開いてからの期間」が長い順にリスト表示（アプリ名・アイコン・最終使用日・サイズ）
- [ ] リストからタップでアンインストール（OSの確認ダイアログ経由）
- [ ] 「使用状況へのアクセス」権限のオンボーディング（許可への誘導画面）

### あとで（v2以降）
- アップデートの有無の表示とアップデート
  ※注：他アプリの更新有無を直接取得する公開APIはない。現実解は「Playストアの該当ページへのリンクを置く」まで。v2検討時に要再調査
- アプリのグループ化（フォルダ・タグ）

### やらない
- インタースティシャル広告
- iOS版（技術的に不可能）
- サイレント一括アンインストール（OS仕様上不可能）

## 7. 技術構成（たたき台）

- **要検討**：この企画はAndroidのネイティブAPI（UsageStatsManager / PackageManager）が中核。選択肢は2つ：
  - A. Expo (React Native) + 自作ネイティブモジュール（Kotlin）：Reactの知識を活かせるが、ネイティブ連携の学習が必要。Expo Goでは動かず、最初からdevelopment build運用
  - B. Android ネイティブ（Kotlin + Jetpack Compose）：APIは素直に呼べるが、言語とUIフレームワークを新規に学ぶ
- データ保存：端末内のみ。**取得したアプリ使用状況を外部送信しない**（プライバシーポリシーに明記。個人情報保護の観点でも審査の観点でも重要）

## 8. リリース計画

- **v1の完成条件**：自分のスマホで実際に不要アプリを10個消せた
- 配布：自分 → 友人にAPK → Google Play（クローズドテスト → 公開）
- 対応OS：**Androidのみ**
- 言語：日本語のみ
