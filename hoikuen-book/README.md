# 連絡帳製本プロジェクト（はいチーズ！ノート → 両面印刷の本）

保育園の連絡帳（日記＋写真）を取り出して、両面印刷・製本できるPDFにするプロジェクト。

## 全体の流れ

1. **収集**：自分のPCで `collect.mjs` を動かし、ブラウザで連絡帳を閲覧 → HTML・写真が `data/` に自動保存される（このステップだけ手作業。ログイン＋日めくり）
2. **自動化**：保存されたHTMLの構造をClaudeが解析し、日付を自動でめくって全期間を収集するスクリプトに進化させる
3. **製本PDF生成**：日付・本文・写真を統一レイアウトに流し込み、綴じ代・ページ番号つきの両面印刷用PDFを生成
4. **印刷・製本**：自宅プリンタ＋製本テープ、またはPDF入稿の冊子印刷サービス

## 事前準備（PC・初回のみ）

1. [Node.js](https://nodejs.org/ja)（LTS版）をインストール
2. このリポジトリをクローンして、このフォルダで：

```bash
cd hoikuen-book
npm install playwright
npx playwright install chromium
```

## 収集の実行

```bash
node collect.mjs
```

- ブラウザが開くので、**自分で**はいチーズ！ノートにログインする（IDとパスワードはスクリプトにもClaudeにも渡さない）
- 連絡帳を1日ずつ表示していく。表示するだけで自動保存される
- 終わったらターミナルで `Ctrl+C`

保存先：
- `data/pages/` … 各画面のHTMLとスクリーンショット
- `data/images/` … 写真（原寸）
- `data/log.jsonl` … 保存記録

## 次のステップ

まず**2〜3日分**だけ収集したら、`data/pages/` のHTMLを2〜3個Claudeに見せる。
→ Claudeがページ構造を解析して「全期間自動収集」と「製本PDF生成」のスクリプトを作る。

PCでClaude Code（デスクトップ版）を使える場合は、このフォルダを開いて
「README.mdを読んで、収集済みのdataから進めて」と伝えれば続きを任せられる。

## 製本の選択肢

| 方法 | 仕上がり | 費用の目安 | 向き |
|---|---|---|---|
| ネット製本（無線綴じ・ソフトカバー） | 背表紙つきの文庫本/写真集スタイル | 1冊1,000〜3,000円程度 | **本命。** PDF入稿で1冊から注文できる |
| ネット製本（ハードカバー） | 絵本のような上製本 | 1冊3,000円〜 | 卒園記念の永久保存版に |
| 自宅印刷＋製本テープ/とじ太くん | 手作り感 | 用紙+インク代 | 試作・下書き確認用 |

PDF入稿・1冊対応の主なサービス：
- [ちょ古っ都製本工房](https://www.chokotto.jp/)（格安の定番）
- [製本直送.com](https://www.seichoku.com/)（1冊から、ハードカバーあり）
- [ブックホン](https://www.book-hon.com/)（PDF入稿割引あり）
- [冊子製本キング](https://www.i-booklet.com/)

**入稿仕様（塗り足し3mm・綴じ代・ページ数の倍数指定など）はサービスごとに違うため、
注文先を決めてからPDF生成スクリプトをその仕様に合わせて作ること。**

おすすめ運用：年度ごとに1冊（例：「2025年度 ○○の連絡帳」）。ページ数が製本に程よく、
毎年増えていく楽しみもある。

## ⚠️ 取り扱い注意

- `data/` には子どもの写真・日記が入る。**絶対にgitにコミットしない**（.gitignoreで除外済み）
- ログインID・パスワードをスクリプトやチャットに書かない
- 収集は自分のアカウントのデータを自分の記念用に保存する目的のみ。手動閲覧と同じペースで動かす（サーバーに負荷をかける連打はしない）
